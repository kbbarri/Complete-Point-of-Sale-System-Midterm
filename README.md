# Point-of-Sale System

A web-based Point-of-Sale (POS) System built using CodeIgniter 4, PHP, and MySQL.

## Features
- Staff Authentication (Login and Logout)
- Product Management (CRUD)
- Customer Management (CRUD)
- Staff Management (CRUD)
- Product Image and Avatar Upload
- Sales Recording
- Automatic Inventory Updates
- Stock Validation
- Sales History

## Technologies Used
- CodeIgniter 4
- PHP
- MySQL
- HTML
- CSS

## Database
The system uses four database tables:
- `products`
- `customers`
- `users`
- `sales`
